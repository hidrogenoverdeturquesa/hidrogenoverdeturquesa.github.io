Prueba editable en LaTeX

Una muestra para comprobar si editar el cuadernillo resulta cómodo y si la web conserva su diseño.

EmpezarVolver al catálogo
Capítulo 1Editar sin tocar HTML

Objetivo de la prueba

Al cambiar estas frases en TeXstudio y volver a generar, se actualizan tanto el PDF como la página web.

Lo que vamos a comprobar

  • Que las tildes y la letra ñ funcionen correctamente.
  • Que las listas sean fáciles de reorganizar.
  • Que el diseño web conserve sus hojas y colores.

Cambios sugeridos

  • Cambia el título de esta columna.
  • Agrega un elemento nuevo a esta lista.
  • Modifica el texto de la siguiente figura.
PrácticaHaz un cambio pequeño

Prueba la edición en TeXstudio

Ejemplo 1

Mi primer cambio

Abre este archivo en TeXstudio, cambia una frase y guarda. Después ejecuta el generador para verla en la web y en el PDF.

  1. Cambia el título. Modifica el contenido de \HVTTitulo.
  2. Edita una lista. Agrega o elimina cualquier elemento escrito con \item.
  3. Genera los resultados. Ejecuta generar-prueba.cmd.
  4. Comprueba el diseño. Abre cuadernillo-prueba-web.pdf.
