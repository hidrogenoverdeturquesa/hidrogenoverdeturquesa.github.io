Objetivo técnico

Estimar la energía útil de un parque solar a partir de irradiación, potencia instalada y pérdidas de sistema.

VariableSímboloUnidad
Irradiación diariaH_dkWh/m²·día
Potencia picoP_pvkWp
Performance ratioPR-
Energía anualE_akWh/año
Ea = Ppv · Hd · 365 · PR

El PR agrupa pérdidas por temperatura, inversor, cableado, suciedad, sombras, disponibilidad y desajustes.

EjemploPredimensionamiento

Ejemplo S-1

Demanda comunitaria

Una comunidad reporta consumo mensual. El diseño debe cubrir una fracción objetivo sin sobredimensionar la red interna.

Procedimiento
  1. Consolidar consumos mensuales.
  2. Definir porcentaje de cobertura solar.
  3. Estimar P_pv usando H_d y PR.
  4. Verificar área disponible y orientación.
  5. Definir medición, reparto y mantenimiento.

Entregable técnico

  • Curva mensual de demanda.
  • Tabla de generación esperada.
  • Mapa de sombras.
  • Esquema de gobernanza comunitaria.
