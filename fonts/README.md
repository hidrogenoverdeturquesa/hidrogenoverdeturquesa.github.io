# Fuentes locales

Este directorio conserva una copia local de las fuentes utilizadas por el
sitio para evitar solicitudes tipográficas a terceros.

- **Manrope v20:** archivos WOFF2 de la respuesta oficial de Google Fonts,
  subconjuntos `latin` y `latin-ext`.
- **Roboto v51:** archivos WOFF2 de la respuesta oficial de Google Fonts,
  estilos normal e italic y subconjuntos `latin`, `latin-ext`, `greek`,
  `math` y `symbols`.

Fuentes oficiales:

- https://github.com/google/fonts/tree/main/ofl/manrope
- https://github.com/google/fonts/tree/main/ofl/roboto
- https://developers.google.com/fonts/docs/css2

Las licencias SIL Open Font License 1.1 se conservan en
`manrope/OFL.txt` y `roboto/OFL.txt`.

`SHA256SUMS` fija la integridad del snapshot descargado el 26 de julio
de 2026.
