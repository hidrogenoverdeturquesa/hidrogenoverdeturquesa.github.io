## Preparación y presentación

- Las cuatro fotografías de Pexels y Unsplash se solicitaron a sus CDN redimensionadas y en formato WebP. La variante `solar-territorio-800.webp` sirve el mismo motivo a menor resolución. La web aplica encuadres mediante CSS (`object-fit` y `object-position`). No se añadieron ni sustituyeron elementos de las escenas.
- `electrolizador.jpg` conserva sin otras modificaciones el JPEG de [960 píxeles de ancho servido por Wikimedia](https://thumb.wikimedia.org/wikipedia/commons/thumb/8/87/Hydrogen_electrolyser_-_Science_Museum%2C_London.jpg/960px-Hydrogen_electrolyser_-_Science_Museum%2C_London.jpg). Es una reducción del original de 3072 × 4080 píxeles. Su presentación puede ajustar el encuadre por CSS; no se alteró el archivo descargado.
